Верни список сценариев из `_status.yml`, отфильтрованный по параметрам.

Параметры (передаются в `$ARGUMENTS` через пробел, парсить вручную):
- `r=<route>` — роут (например `r=products`, `r=_home`)
- `t=<scenario>` — имя сценария (например `t=search-product`)
- `s=<status>` — статус из `_status.yml` (например `s=planned`, `s=base_test_generated`)

Фильтрация:
- Если `r` задан — только сценарии в `app/<r>/_status.yml`
- Если `t` задан — только сценарии с `<t>` в имени (match по подстроке)
- Если `s` задан — только сценарии с совпадающим статусом
- Если ни один параметр не задан — все сценарии из всех `app/*/_status.yml`

Формат вывода — по одному сценарию на строку:

```
<route>/<scenario>
```

Пример: `s=planned` → все planned-сценарии. `r=products s=base_test_generated` → все base_test_generated в роуте products.
