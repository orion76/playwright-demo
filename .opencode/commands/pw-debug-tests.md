Выполни отладку тестов.

Параметры:
- `path` — путь к конкретному тесту (если передан — отлаживается только он)
- Все остальные аргументы (r, t, s, v, u, l) передаются в `@.opencode/commands/pw-get-tests.md` для фильтрации списка

Примеры:
```
/pwdt path=tests/login/ideal/login-correct--desktop--guest--en.spec.ts
/pwdt r=login s=base_test_generated
/pwdt r=products t=search-product
```

**Порядок:** сначала отлаживается базовый тест (`desktop`, `en`). После его прохода — генерация и отладка остальных комбинаций.

1. @.opencode/skills/check-connectivity/SKILL.md

2. Получи список тестов для отладки:
   - Если передан `path` — используй его как единственный файл
   - Иначе — получи список через `@.opencode/commands/pw-get-tests.md` с переданными аргументами

3. **Цикл по тестам.** Для каждого теста в списке:

   3.1 Если тест уже помечен как `✅ DONE` — пропусти.

   3.2 Сформируй имя запуска: `<v>-<l>` (например `mobile-en`).

   3.3 Запусти тест:
   ```
   LANG=<l> npx playwright test "<path>/<file>.spec.ts" \
     --project=<v> \
     --reporter=list,html \
     --workers 1 --timeout 120000 --retries 0 --max-failures 1
   ```
   - `PLAYWRIGHT_HTML_REPORT=playwright-report/<v>-<l>/` — отдельный отчёт
   - `--output=test-results/<v>-<l>/` — отдельные артефакты

   3.4 Если тест **прошёл:**
       - Пометь как `✅ DONE [<v>-<l>]`
       - Переходи к следующему тесту

   3.5 Если тест **упал — проанализируй причину:**

       | Симптом | Скорее всего | Действие |
       |---------|-------------|----------|
       | `locator not found`, `timeout 30000ms` | Ошибка в тесте | Исправь локатор/ожидание |
       | `expected X to be Y` но поведение по spec/*.md другое | **Баг приложения** | Запиши в `app/<r>/issues.yaml`, переходи к следующему |
       | `expected X to be Y` и spec/*.md описывает именно Y | **Баг в сценарии** | Исправь `spec/<t>.md`, затем тест |
       | `console.error` на странице | **Баг приложения** | Запиши в `issues/todo.yml` |
       | `403/500` от API | **Бэкенд / данные** | Проверь моки |
       | `page crashed`, белый экран | **Баг приложения** | Запиши в `issues/todo.yml`, пропусти |
       | Элемент скрыт при данном viewport | **Адаптивность** | Исправь тест |

       Правила расхождения — из @.opencode/skills/test-base/test-code-rules.md.

   3.6 После исправления — запусти только упавший тест снова (шаг 3.3).
       Для изоляции используй `test.only`. После отладки удали `.only`.

   3.7 Если тест не удаётся исправить за 5 попыток — спроси пользователя.

4. После прохода всех тестов сообщи результат:
   ```
   ✅ Отладка завершена [<v>-<l>]
   Пройдено: N
   Пропущено (баг приложения): M
   Отчёт: playwright-report/<v>-<l>/index.html
   Issues: app/<r>/issues.yaml / issues/todo.yml
   ```
