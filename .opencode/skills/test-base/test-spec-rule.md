# Spec Rules

Правила генерации идеальных сценариев (`spec/<название>.md`).

## 1. Проверка наличия всех локаторов перед тестом

Перед началом каждого сценария проверить, что все статичные элементы (заголовки, кнопки, поля ввода, метки) присутствуют на странице.

```ts
// После открытия страницы, до любых действий:
await expect(t.region("regionName").block("blockName").element("elementName")).toBeVisible();
```

Проверяются:
- Заголовки страницы и разделов
- Кнопки навигации (Next, Go Back, сабмит)
- Поля ввода (текстовые, даты, select, чекбоксы)
- Элементы сайдбара (список шагов)
- Любые статичные текстовые метки

Исключение: элементы, которые появляются только после взаимодействия (дропдауны, модальные окна, тултипы, раскрывающиеся секции).
