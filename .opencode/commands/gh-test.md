Запускает полный прогон тестов на GitHub Actions, скачивает артефакты, анализирует упавшие тесты и отлаживает их.

Если передан `--push` — сначала делает коммит и пуш (на случай незакоммиченных изменений).

Параметры:
- `--push` — закоммитить и запушить перед запуском (опционально)
- `--project desktop` — проект для локальной отладки (по умолчанию `desktop`)

**Порядок:**

1. Если флаг `--push` — сохранить и запушить изменения:
   ```
   git add -A
   git commit -m "wip"
   git push
   ```

2. Запустить workflow на GitHub:
   ```
   gh workflow run test.yml
   ```

3. Дождаться завершения прогона. Получить ID run:
   ```
   gh run list --workflow=test.yml --limit=1 --json=databaseId --jq=.[0].databaseId
   ```
   Ждать завершения:
   ```
   gh run watch <ID> --exit-status
   ```
   Если `--exit-status` вернул ошибку — тесты упали, это нормально, продолжаем.

4. Скачать артефакты:
   ```
   gh run download <ID> --dir .gh-artifacts
   ```

5. Прочитать HTML-отчёт Playwright. В `.gh-artifacts/playwright-report/` открыть `index.html`:
   - Извлечь список пройденных/упавших тестов
   - Для каждого упавшего — прочитать `trace.zip` (если есть), скриншоты, ошибки

6. Показать пользователю сводку:
   ```
   Результаты прогона: https://github.com/<owner>/<repo>/actions/runs/<ID>
   Всего тестов: N
   Пройдено: N
   Упало: N
   Артефакты: .gh-artifacts/
   ```

7. Если есть упавшие тесты — запустить `/debug-tests` для каждого файла из списка упавших.

   Для каждого упавшего теста:
   7.1 Извлечь путь к spec-файлу из отчёта
   7.2 Прочитать ошибку из `test-results/`
   7.3 Запустить локальную отладку:
   ```
   LANG=en npx playwright test "<path>" \
     --project=<project> \
     --reporter=list,html \
     --workers 1 --timeout 120000 --retries 0 --max-failures 1
   ```
   7.4 Анализировать причину падения (см. таблицу в `/debug-tests`).
   7.5 Исправить и перезапустить до зелёного.

8. После отладки всех тестов — очистить артефакты:
   ```
   rm -rf .gh-artifacts
   ```

9. Сообщить результат.
