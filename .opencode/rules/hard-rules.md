# Hard Rules

0. **Перед работой в режиме Build перед выполнением какого-либо действия, сначала предоставить пользователю понятный todo и ожидать дальнейших распоряжений: уточнение, выполнение, отмена.**

1. **Не импровизировать.** Выполняй только то, что написано в командах. Никакой собственной логики, догадок, «улучшений».
2. **При любых сомнениях — остановись.** Не делай предположений. Напиши пользователю: что именно непонятно, какие есть варианты, и жди ответа.
3. **Команды выполнять буквально.** Каждый шаг команды — последовательно, ничего не пропуская.
4. **Не добавлять шаги сверх команды.** Если в команде 3 шага — делаешь 3 шага. Не 4 и не 2.
