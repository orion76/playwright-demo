Прочитай все `app/*/_status.yml` файлы, сгруппируй сценарии по статусам и выведи таблицу.

**Порядок статусов (от начала к концу):**
1. `planned` — запланирован
2. `scenario_written` — сценарий написан
3. `base_test_generated` — базовый тест сгенерирован
4. `test_generated` — все комбинации сгенерированы

**Формат вывода:**

Сначала строка-счётчик:

```
Всего сценариев: N
```

Затем двухуровневое дерево. Группы отсортированы по порядку статусов. Внутри группы — по одному сценарию на строку.

```
<status> (N)
  <route>/<scenario>
  <route>/<scenario>
  ...

<status> (N)
  <route>/<scenario>
  ...
```
